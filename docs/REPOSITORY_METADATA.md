# Recommended GitHub Repository Metadata

Apply these values in **Settings → General** and the repository's About panel.

## Description

A curated developer toolkit with 82 skills, MCP setup guides, and cross-agent instructions for Claude Code, ChatGPT, and Codex.

## Topics

Use a focused set (GitHub limits topic count):
`ai-agents`, `agent-skills`, `claude-code`, `codex`, `chatgpt`, `mcp`, `developer-tools`, `developer-productivity`, `security`, `testing`

## Homepage

Leave blank until there is a maintained documentation website or demo. The GitHub repository itself is a better destination than a dead link.

## Social preview

Recommended image: 1200 × 630 px. Include:
- MDCP name and a short subtitle
- A clear visual showing skills + MCP + multiple agent hosts
- High contrast and readable typography at small sizes
- No unsupported compatibility badges or fake usage metrics

## GitHub features

- Issues: enabled
- Projects: optional; use only if the roadmap is actively maintained
- Wiki: optional; prefer version-controlled docs for canonical instructions
- Discussions: enable, then create categories and starter posts from COMMUNITY_DISCUSSIONS.md
- Sponsorships: enable only if a real funding destination exists

## Suggested pinned repositories

Pin MDCP only after the README, installation path, and release are in good shape. Pinning is an account-profile action and must be done by the repository owner.
