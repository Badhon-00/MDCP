## Short project announcement

I'm building **MDCP**, a curated toolkit for AI-assisted software development.

It brings together 82 documented skills, MCP setup notes, and separate companion guidance for Claude Code, ChatGPT, and Codex. The focus is practical: security reviews, testing, frontend/backend workflows, and shipping software with clearer checks.

The project preserves upstream skill attribution and keeps host-specific integration formats separate instead of claiming one plugin works everywhere.

Repository: https://github.com/Badhon-00/MDCP

I'd especially value feedback from developers who use more than one coding agent: what installation path or workflow should be tested next?
