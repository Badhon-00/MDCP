# MDCP Community Discussions

This file is the setup and seed-post plan for GitHub Discussions. Discussions must first be enabled by a repository administrator in **Settings → General → Features → Discussions**. After enabling it, create the categories below and publish the starter posts. Do not present issue threads as Discussions.

## Recommended categories

| Category | Format | Purpose |
|---|---|---|
| Announcements | Announcement | Releases, breaking changes, compatibility updates |
| General | Open-ended | Community conversation and introductions |
| Q&A | Question / Answer | Installation, configuration, and usage help |
| Ideas | Open-ended | New skills, integrations, and workflow proposals |
| Show and tell | Open-ended | Demos, examples, and adoption stories |

## Starter discussion 1 — Welcome

**Title:** Welcome to MDCP — introduce yourself and your AI coding workflow

**Body:**

Welcome! MDCP is a curated developer toolkit with skills, MCP setup notes, and separate companion guidance for multiple AI coding environments.

To help us make it more useful, tell us:
- Which coding agent or host do you use most?
- Which operating system and editor are you using?
- What kind of work do you use agent skills for?
- Which part of setup or day-to-day use is currently frustrating?

Please share actual workflows and reproducible details. Be respectful, and do not post API keys, access tokens, private logs, or personal data.

## Starter discussion 2 — Compatibility reports

**Title:** Compatibility reports — which host and version have you tested?

**Body:**

We want a compatibility matrix based on real tests rather than assumptions.

Please report:
- Host: Claude Code, claude.ai, ChatGPT, Codex, or another host
- Host version / plan / platform, if relevant
- OS and shell
- Exact installation method
- What worked
- What failed, with redacted error output
- Whether the result is repeatable

Important: a Markdown skill, a Claude plugin, an MCP server, and ChatGPT app/plugin integrations are not interchangeable. Mark untested combinations as untested.

## Starter discussion 3 — What should we build next?

**Title:** Help shape the MDCP roadmap

**Body:**

Which improvement would most help you adopt MDCP?

Examples:
- A tested one-command installer for a specific host
- Better Codex skill packaging
- More verified MCP provider guides
- Minimal starter bundle for a specific stack
- Security and provenance checks for third-party skills
- More real-world walkthroughs

Describe the problem and the outcome you need. If possible, link a small reproducible example.

## Starter discussion 4 — Show and tell

**Title:** Show what you built with MDCP

**Body:**

Share a project, workflow, or task where an MDCP skill or guide helped. Include the relevant skill, host, setup steps, and what changed in your workflow.

Only share work you have permission to publish. No fake testimonials or inflated performance claims.

## Moderation rules

- Keep discussion constructive and on-topic.
- No spam, fake engagement, purchased stars, or unrelated promotion.
- Never share secrets or private user data.
- Be clear about tested versus untested compatibility.
- Report security issues privately using SECURITY.md, not a public discussion.
