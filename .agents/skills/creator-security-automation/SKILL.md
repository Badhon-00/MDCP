# Creator + Security Automation
Use the canonical workflow in `skills/creator-security-automation/SKILL.md`. Route only to the requested task.

- Security: passive website checks, authorized asset inventory, SQL injection/XSS prevention, auth/session/API review, dependency and secret review, remediation and retesting.
- E2E: Playwright journeys, role/permission cases, API contracts, accessibility, responsive checks and regression tests using staging and synthetic data.
- YouTube: strategy, research, scripts, thumbnails, captions, FFmpeg/editor workflows, QA, metadata, private-by-default uploads, playlists and analytics.
- Copyright: track asset licenses/permissions and use original or licensed media. Never bypass Content ID or disguise copied content.
- Safety: only test systems with explicit authorization. No credential theft, malware, persistence, stealth, exfiltration or unauthorized exploitation. Require approval for publishing, deletion and external mutations.
- Tool: `mdcp`, one operation per call. The tool supports passive security audit, heuristic SQL review, E2E test planning and delegation to the YouTube API runtime when configured.
