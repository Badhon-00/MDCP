# Creator + Security Automation
Canonical workflow: `skills/creator-security-automation/SKILL.md`.

- Authorized security: passive HTTPS/header review, SQL injection/XSS prevention, authentication/session/API checks, dependency and secret review, remediation and retesting.
- E2E: Playwright journeys, roles/permissions, API contracts, accessibility, responsive checks and regression tests in staging with synthetic data.
- YouTube: channel strategy, topic research, scripts, thumbnail generation, editing/FFmpeg, captions, QA, SEO metadata, approved uploads, playlists and analytics.
- Copyright: keep license/permission records; use original or licensed assets; never evade Content ID or disguise copied content.
- Safety: explicit authorization required for security testing. No unauthorized exploitation, credential theft, malware, stealth or exfiltration. Publishing and destructive actions require approval.
- Tool: `mdcp`, one operation per call; YouTube delegation requires configured API credentials and runtime.
