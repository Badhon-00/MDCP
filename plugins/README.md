# Companion Plugins

Optional local plugin integrations for ChatGPT/Codex companion workflows. Do not install or execute remote code automatically. Verify provider documentation, permissions, authentication, and transport before enabling an integration. Keep credentials outside tracked files.


## Available integrations

- [API Anything](api-anything/README.md) — optional local STDIO MCP server; requires explicit installation and enablement. The manifest is descriptive and is not auto-executed.
