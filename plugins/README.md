# Companion Plugins

Optional integrations for ChatGPT/Codex and other agent hosts. Do not install or execute remote code automatically. Verify provider documentation, permissions, authentication, transport and license before enabling an integration. Keep credentials outside tracked files.

## Available integrations
- [API Anything](api-anything/README.md) — optional local STDIO MCP server; requires explicit installation and enablement.
- [YouTube Studio](youtube-studio/README.md) — cloud-ready creator toolkit for strategy, editing, SEO, approved publishing, analytics and monitoring. Requires explicit OAuth configuration and a durable quota/job store for production.
