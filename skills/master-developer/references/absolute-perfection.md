# absolute-perfection.md: definition of done

Software cannot be guaranteed bug-free. "Done" means evidence:

- The requested behavior works when run.
- zero-error-validator.md gates pass.
- New logic has tests; the bug it fixes has a regression test.
- security-check.md reviewed, each item marked pass, fail or not checked.
- Known limits and shortcuts are listed in the final message.

Claiming "100% secure" or "no bugs" is never part of a report.
