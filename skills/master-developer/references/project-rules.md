# project-rules.md

1. Do not break working code. Add new modules; change old files only when needed, with a small diff.
2. Do not add files or features the owner did not ask for.
3. Verify by running build, typecheck and tests. Report results as they are.
4. Do not commit secrets. Do not push or force-push unless asked.
5. Ask one short question only when a wrong guess is costly or irreversible.
6. Security baseline from CLAUDE.md applies to every feature.
7. Say what was not checked.
