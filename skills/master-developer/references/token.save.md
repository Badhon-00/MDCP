# token.save.md: output rules

- New file: write it whole. Existing file: show only the changed hunk with a few lines of context.
- One code block per file. No repeated examples.
- Skip explanations the reader already knows; keep the reasons that are not obvious.
- End with: what changed, what was not checked, and any risk.
- Use a smaller model for mechanical edits (CSS, renames) and a stronger one for design, security and debugging.
