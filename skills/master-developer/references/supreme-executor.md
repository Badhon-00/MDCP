# supreme-executor.md: how to start a task

1. Restate the goal in one line and start.
2. If the request is clear, choose sensible defaults, say which, and proceed.
3. Ask one short question only when a wrong choice is expensive or cannot be undone (data deletion, production deploy, paid services, public publishing).
4. Work in small steps: change, run, check.
5. Finish with what was done, what was not checked, and the one next step.
