# uiux.md

- Start from the project's design tokens (see design-tokens.md). No hardcoded colors or spacing.
- 8px spacing grid, one type scale, two font roles at most.
- Every data view has loading, empty, error and success states.
- Buttons: default, hover, focus-visible, active, disabled, loading.
- Contrast WCAG AA (4.5:1 text). Full keyboard path. Visible focus ring.
- Works at 400px wide. No horizontal page scroll.
- Respect `prefers-reduced-motion`. Animate transform and opacity only.
- Avoid stock looks: purple gradients, generic glass cards, emoji as icons. Pick a direction from the product's subject.
