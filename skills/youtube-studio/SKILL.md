# YouTube Studio
Use this skill to coordinate YouTube work without treating growth as guaranteed.

1. Establish channel ownership, audience, niche, language, cadence, format and media rights.
2. Research topics and competitor videos with attributable public data; record URLs and retrieval dates.
3. Build a brief: audience promise, hook, outline, script, visual plan, narration, captions, thumbnail concept and metadata.
4. Produce with FFmpeg or the user's selected editor. Preserve source assets; do not overwrite originals by default.
5. Check facts, spelling, audio, aspect ratio, captions, permissions, thumbnail and policy risks.
6. Present a preview. Require explicit approval before upload, public visibility, scheduling, comments or playlist changes.
7. Collect permitted metrics at consistent intervals and recommend evidence-based experiments.

Cloud: keep handlers stateless, OAuth secrets in a secret manager, jobs in a durable queue, quota usage in shared storage, and long renders in workers. Make uploads idempotent.

Never buy engagement, automate spam, evade quotas, bypass copyright controls or download media without rights. Public Data API stats are not private retention/revenue metrics. Default uploads to private.
