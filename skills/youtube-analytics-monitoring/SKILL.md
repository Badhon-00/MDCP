# YouTube Analytics and Monitoring
Use Data API for public metadata/statistics and YouTube Analytics API with OAuth for owner metrics.

Track where available: views, watch time, average view duration, retention, impressions, CTR, subscribers gained/lost, traffic sources and returning viewers. Metric availability depends on report dimensions and permissions.

- Collect snapshots on a predictable schedule with timestamps.
- Compare videos against the channel's own comparable cohorts.
- Flag upload/processing failures, missing thumbnails, unusual changes and quota exhaustion.
- Set thresholds from historical variance; avoid universal benchmarks.
- Include definitions, time window, sample size and source in reports.
- Recommend one test at a time and evaluate after sufficient data.

Do not imply public APIs expose private retention, revenue or demographics without owner authorization.
