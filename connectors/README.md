# Connectors and MCP

Connector categories may include Git providers, documentation search, databases, design tools, browser testing, deployment, observability and team workflow systems. Examples include GitHub, Context7, Supabase, Figma, Playwright, Vercel, Cloudflare, Sentry, Linear and Notion.

These are integration targets, not a claim that all connectors are bundled, verified, free or available in every host. Confirm publisher, source, permissions and version. Prefer read-only access first, least privilege, host secret storage and explicit approval for writes/deployments. Never commit API keys. Remove unused connectors and rotate exposed credentials. See mcp/ for existing setup notes.
